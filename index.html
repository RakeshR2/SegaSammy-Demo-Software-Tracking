Standard Operating Procedure Highlights

1. Single Cabinet License Restriction — Each software media set is licensed for use on ONE cabinet at a time. Do not copy, clone, image, or transfer software onto multiple machines.

2. Lockbox Security — When not in active demonstration, all physical media (CFast, BIOS, USB) must be locked in the secure storage box.

3. Special Function Safeguards — Diagnostic and forced-outcome inputs (jackpot/credit simulation) are strictly confidential to designated personnel.

4. Location Control — Software must remain at R2 Gaming showroom/office premises. No offsite removal without explicit manufacturer written consent.

5. Return & Deletion Protocol — Upon manufacturer request, media must be returned within 5 business days, and all temporary copies deleted with written certification.
